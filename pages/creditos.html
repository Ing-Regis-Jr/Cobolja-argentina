4. Tecnologías y servicios

El sitio es estático: no usa cuentas ni servidor propio. El apodo y los puntajes de los juegos se guardan solo en el navegador de cada persona.

  • Base del sitio: HTML5, CSS3 y JavaScript, sin frameworks.
  • Leaflet 1.9.4: biblioteca de mapas interactivos de código abierto. leafletjs.com
  • OpenStreetMap: datos y mosaicos del mapa, © colaboradores de OpenStreetMap (licencia ODbL).
  • Atkinson Hyperlegible: tipografía del Braille Institute pensada para la legibilidad, servida por Google Fonts (licencia SIL Open Font License).
  • qrcode-generator (Kazuhiko Arase, licencia MIT): librería que dibuja el código QR para compartir el sitio. Si no carga, se usa el servicio QR Server como respaldo. GitHub
  • Imágenes: Wikimedia Commons, Unsplash y las ilustraciones originales de las portadas (ver sección 2).
  • Herramientas de desarrollo: Visual Studio Code, Git y GitHub.
Uso educativo

Este sitio es un trabajo escolar sin fines de lucro. Los textos e imágenes de terceros se usan con fines educativos y con crédito a sus autores.
